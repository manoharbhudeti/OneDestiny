1. Executive Summary & Brand Visual Identity

OneDestiny is an elite event and celebration marketplace bridging discerning event hosts with certified top-tier vendors across weddings, corporate galas, private celebrations, photography, venue bookings, catering, luxury transportation, and entertainment.

Brand Color Tokens

Color Name Hex Code RGB Value Role / Application
Imperial Burgundy #6B1028 RGB(107, 16, 40) Primary brand color, luxury app bars, primary CTA buttons, active accents.
Dark Burgundy #30040E RGB(48, 4, 14) Splash screen gradient origin, bottom navigation active pill container.
Champagne Gold #D4AF37 RGB(212, 175, 55) Metallic brand typography, star emblem, borders, icons, rating badges.
Warm Ivory #FFFDF9 RGB(255, 253, 249) Light mode canvas, surface cards, and modal background surfaces.
Obsidian Black #121212 RGB(18, 18, 18) OLED dark mode surfaces, high contrast cards, and luxury header in dark mode.

Brand Emblem Specifications

The official OneDestiny emblem features a 3D beveled infinity motif signifying eternal celebratory memories. At the nexus of the emblem sits a four-pointed radiant celebration star. The typography uses a refined high-contrast serif typeface, anchored by symmetrical gold decorative flanking rules framing the core slogan: "MAKE EVERY CELEBRATION IN ONE PLACE".

Antialiasing & Asset Edge Purity: All brand assets undergo 5×5 spatial Gaussian smoothing, cubic Hermite S-curve alpha interpolation, and color inpainting/dilation to eliminate halos, ensuring crisp rendering across burgundy, white, and black surfaces.

2. Technical Architecture & Engineering Stack

OneDestiny is engineered following a clean, modular, feature-first architecture that strictly isolates the presentation layer, application business logic, repositories, and platform services.

System Layered Architecture

graph TD A["UI Layer (Screens & Custom Widgets)"] --> B["AppStateScope (InheritedWidget)"] B --> C["AppState (ChangeNotifier)"] C --> D["AppRepository (Data Orchestration)"] D --> E["ApiService (REST Client & Interceptors)"] D --> F["AuthStorageService (Encrypted Local Storage)"] D --> G["Firebase SDK (Auth, FCM, Analytics)"] A --> H["10 Canonical UI States Engine"] H --> I["NetworkStateHandler (Offline & 401 Bus)"]

Core Engineering Technologies

Layer Technology Description & Responsibilities
Framework Flutter SDK (Dart 3.x) Universal multiplatform codebase powering Android, iOS, and Web.
State Management AppStateScope & AppState Decoupled reactive state with zero third-party boilerplate.
Networking ApiService + Dio / HTTP Automated Bearer token injection, retry mechanisms, and error sanitization.
Persistence AuthStorageService Secure storage for session tokens, user profile, and cached bookmarks.
Cloud & Notifications Firebase Core & FCM Cloud messaging, analytics telemetry, and phone auth verification.

3. The 10 Canonical UI States Architecture

To deliver a resilient, ultra-luxury experience, OneDestiny enforces 10 canonical UI states across all user-facing surfaces. No screen presents a blank canvas or uncaught exception.

# State Name Component Behavior & Design Treatment
1 Empty State EmptyStateWidget Contextual gold illustration, explanatory copy, and direct navigation CTA.
2 Loading State SkeletonLoaderCard Smooth gradient shimmer pulses matching the exact layout of loaded cards.
3 Error State ErrorStateCard Human-readable error sanitization with a debounced "Try Again" trigger.
4 Offline State OfflineBanner / NoInternetWidget Custom 2D vector graphic with automated reconnect listener.
5 Slow Network SlowNetworkNotice Non-blocking amber banner advising the customer of high latency.
6 No Search Results NoResultsStateWidget Displays queried term with suggestion pills and "Clear Filters" CTA.
7 Permission Denied PermissionDeniedWidget Explains rationale for Location or Notifications with deep links to settings.
8 Session Expired SessionExpiredDialog Non-dismissible luxury modal for HTTP 401s; flushes tokens and redirects to Login.
9 Form Validation FormFieldFeedback Real-time input outline transition to Crimson Red (#E53935) with inline hints.
10 Success State SuccessStateWidget Spring-animated luxury checkmark with confirmation details and return action.
